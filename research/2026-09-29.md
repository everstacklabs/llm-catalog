## Wider release coverage and limitations

- [Google September releases](https://ai.google.dev/gemini-api/docs/changelog):
  Gemini 3.8 Live / Live Extended Thinking, Flash TTS / Flash-Lite TTS, Lyria 3.5,
  and Antigravity Agent were reviewed. Their distinct realtime, audio/music, and
  managed-agent protocols are not implemented by the current Google text adapter;
  advertising them as chat models would be incorrect.
- [OpenAI GPT-Live-1 API](https://openai.com/index/introducing-gpt-live-1-in-the-api/):
  September API availability uses a distinct Live protocol, deferred from this
  catalog-only update.
- [Qwen releases](https://docs.qwencloud.com/changelog/models): realtime
  translation/voice models require protocol and modality-specific billing work.
  New supported text-output routes are included through OpenRouter where verified.
- [xAI releases](https://docs.x.ai/developers/release-notes): Voice Transcribe 2.0
  requires a speech adapter. Grok 4.7 Fast is not a public xAI API model.
- [Claude Fable/Mythos 5.1](https://platform.claude.com/docs/en/models/fable-5-1/overview):
  Mythos is invitation-only and is not advertised as generally available.
- [Mistral release notes](https://docs.mistral.ai/resources/release-notes): no
  verified September model addition from the reviewed release notes; Vibe product
  changes are not model releases.
- Cohere, Meta, Qwen, Z.ai, Xiaomi, Fireworks, Inception, Sakana, and smaller labs
  are represented by verified OpenRouter offerings. No direct or cloud-hosted
  endpoint is inferred from an OpenRouter identifier. NVIDIA, Moonshot, MiniMax,
  and Voyage had no additional verified in-window API model in this review.

This is a best-effort API catalog review, not an exhaustive registry of every
research checkpoint or product announcement. Adding a catalog row verifies
metadata, not account access or a successful provider inference call.
